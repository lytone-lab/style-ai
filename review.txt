# STYLE AI - PROJECT CONTEXT & AI ONBOARDING

## Vision
Build a billion-dollar, Cal AI-inspired mobile-first PWA for fashion. It transitions from a simple outfit analyzer into a daily habit loop tracking Wardrobe Economy, Cost-Per-Wear, and Predictive Contextual Styling.

## Tech Stack
- **Framework:** Next.js 15.5 (App Router, Webpack, `next.config.ts` configured for Windows SWC).
- **Styling:** Tailwind CSS (Mobile-first strict container: `max-w-md mx-auto`, dark mode `#000000` base, `#111111` cards, `#FFFFFF` text, massive font-black typography).
- **Database:** Supabase Cloud (Currently only Waitlist is wired. Auth and Cloud Sync are the next priority).
- **AI:** Groq Cloud (`qwen/qwen3.8-27b` for Vision), MediaPipe (`@mediapipe/tasks-vision` for local face mesh/undertone analysis).
- **Deployments:** GitHub Actions CI, pushing to `https://github.com/lytone-lab/style-ai`.

## Current State (What is built)
1. **Landing Page (`/`)**: Mobile-locked Cal AI UI with massive buttons.
2. **Dashboard (`/dashboard`)**: SVG Harmony Ring, localStorage history, bottom navigation.
3. **Outfit Analyzer (`/analyze/outfit`)**: Uploads to Groq, gets Vibe, Archetype, Score, and 3 Fixes. Uses a full-screen sequential loading state.
4. **Color Analyzer (`/analyze/color`)**: MediaPipe face tracking with a dense cinematic white mesh. Calculates undertone via CIELAB math.
5. **Virtual Studio (`/dashboard/try-on`)**: Preview mode for virtual try-on (Canvas pan/zoom, garment carousel). No Fal.ai integration yet.

## Immediate Next Steps (The Roadmap)
- **Phase 1:** Setup Supabase Authentication (Email/Password & OAuth) and replace `localStorage` with Cloud Database.
- **Phase 2:** Digital Closet & Cost-Per-Wear.
- **Phase 3:** Coarse-to-Fine Adjuster & Arbitrage Engine.
- **Phase 4:** True AI Try-on (Fal.ai) and AI Chat Stylist.

## AI Instructions
- **Commands:** Always provide PowerShell commands to write files using here-strings (`@' ... '@ | Set-Content -Path "..." -Encoding utf8`).
- **System Constraints:** Execution policies might block npm. Remind the user to run `Set-ExecutionPolicy -ExecutionPolicy Bypass -Scope Process -Force` if needed.
- **UI Rules:** NEVER use glassmorphism or soft clay shadows. Strict Cal AI / Neo-Brutalist aesthetic. 1px borders (`border-[#222222]`), stark white buttons.
- **Errors:** If Next.js throws a TensorFlow console error, override `console.log`, `console.info`, and `console.warn` in the `detectForVideo` loop.

## UI/UX Laws & Behavioral Design (STRICT RULES)
The app must weaponize these cognitive principles to maximize conversion and retention:
- **Hick's Law:** Minimize decisions. (e.g., Replace complex text-editing grids with a single, intuitive visual slider for cropping).
- **Fitts's Law:** Make primary actions massive and reachable. (e.g., h-[72px] sticky bottom buttons, large touch targets).
- **Jakob's Law:** Use familiar patterns. (e.g., Standard bottom sheets, native range sliders).
- **Law of Proximity:** Group related elements visually. (e.g., Image, title, and CPW inside a single bordered card).
- **Miller's Law (7±2):** Reduce cognitive load. Show max 3 items per card or use visual badges (+3 items) instead of long text lists.
- **The IKEA Effect:** Users value what they help create. Forcing a quick manual crop makes them invest in their digital closet.

# STYLE AI - THE ROADMAP TO A BILLION DOLLARS

This document outlines all remaining features required to transition from the MVP to a sticky, monetizable, daily-habit app.

## 1. The Wardrobe Value & Velocity Loop (Cost-Per-Wear)
- **What it is:** Tracking how much value a user gets out of their clothes. Every time a user logs an outfit, the `wear_count` increments for those specific items.
- **The Utility:** The dashboard displays a "Closet Depreciation Meter." A $200 jacket worn 10 times is $20/wear. A $80 shirt worn 0 times is $80/wear.
- **Behavioral Hook:** Triggers data investment. Users won't delete the app because their financial wardrobe history lives there.

## 2. Predictive Context Engine (Pre-emptive Styling)
- **What it is:** A background function that runs at 7:00 AM. It pings a Weather API and the user's Calendar.
- **The Utility:** Instead of waiting for a scan, it sends a push notification: "It's 11°C and raining, but you have a formal meeting at 2:00 PM. Tap to see 3 optimal combinations from your saved wardrobe."
- **Behavioral Hook:** Shifts the app from reactive (rating outfits) to proactive (telling you what to wear).

## 3. The Interactive Coarse-to-Fine Adjuster
- **What it is:** An editable slide-up sheet displaying the AI's parsed JSON after a scan. Every item is an editable tag. Tapping "Charcoal Hoodie" opens a menu: [Edit Color | Change Material | Swap Layer].
- **The Utility:** Removes frustration when the AI guesses wrong. Ensures data written to Supabase is pristine.
- **Behavioral Hook:** Gives the user total control over their digital closet.

## 4. Single-Item Gap Arbitrage (The Core Monetization)
- **What it is:** An algorithm that scans the user's database. It identifies structural limitations (e.g., user has 5 dark trousers and 4 blazers, but 0 light base layers).
- **The Utility:** The dashboard generates a micro-card: "You are missing a Cream Micro-Rib Tee. Adding this unlocks 9 new outfit configurations with items you already own."
- **Behavioral Hook:** Clicking the card opens a native checkout (affiliate link). You monetize the missing link.

## 5. Supabase Authentication & Cloud Storage
- **What it is:** Full auth (Email/OAuth). Uploading scanned images to Supabase Storage buckets. Syncing the dashboard history.
- **The Utility:** Users can log in on a new phone and their entire wardrobe is there. No more `localStorage` amnesia.

## 6. True AI Try-On (Premium Tier)
- **What it is:** Replacing the "Preview Mode" with Fal.ai/Replicate InstantID integration.
- **The Utility:** The AI literally puts the shirt on the user's body.
- **Monetization:** Lock this behind a $5/mo paywall to cover API costs.

## 7. The AI Chat Stylist
- **What it is:** A text interface where a user can say: "I have a dinner date at a rooftop bar tonight. Pick an outfit from my closet."
- **The Utility:** The AI parses their Supabase database and outputs a specific outfit combo.

## 8. Viral Onboarding & Paywall
- **What it is:** A 5-question quiz before the dashboard (Vibe, Budget, Body Type).
- **The Utility:** Cognitive dissonance. After investing 2 minutes answering questions, users convert to the $4.99/mo subscription at a much higher rate.

function samplePatch(context: CanvasRenderingContext2D, width: number, height: number, landmark: FaceLandmark, offsetY = 0): RGB[] {
  const centerX = Math.round(landmark.x * width); const centerY = Math.round((landmark.y + offsetY) * height);
  const radius = 4; const left = Math.max(0, Math.min(width - 1, centerX - radius)); const top = Math.max(0, Math.min(height - 1, centerY - radius));
  const patchWidth = Math.min(radius * 2 + 1, width - left); const patchHeight = Math.min(radius * 2 + 1, height - top);
  const pixels = context.getImageData(left, top, patchWidth, patchHeight).data; const samples: RGB[] = [];
  for (let index = 0; index < pixels.length; index += 4) { samples.push([pixels[index], pixels[index + 1], pixels[index + 2]]); }
  return samples;
}

function getLightingWarning(context: CanvasRenderingContext2D, width: number, height: number): string | null {
  const pixels = context.getImageData(0, 0, width, height).data; let luminanceTotal = 0; let clippedPixels = 0; const pixelCount = pixels.length / 4;
  for (let index = 0; index < pixels.length; index += 4) {
    const red = pixels[index]; const green = pixels[index + 1]; const blue = pixels[index + 2];
    luminanceTotal += 0.2126 * red + 0.7152 * green + 0.0722 * blue;
    if (red > 248 && green > 248 && blue > 248) clippedPixels += 1;
  }
  const averageLuminance = luminanceTotal / pixelCount;
  return averageLuminance < 70 || averageLuminance > 225 || clippedPixels / pixelCount > 0.35 ? LIGHTING_WARNING : null;
}

// ===== THE CORRECT CINEMATIC FULL FACE DENSE MESH =====
function drawMesh(context: CanvasRenderingContext2D, landmarks: FaceLandmark[], width: number, height: number) {
  context.clearRect(0, 0, width, height);

  const visionLib = window.tasksVision ?? window.Vision;
  // Retrieve the official tesselation array from the loaded MediaPipe bundle
  const tesselationPairs = visionLib?.FaceLandmarker?.FACE_LANDMARKS_TESSELATION;

  context.strokeStyle = "rgba(255, 255, 255, 0.15)"; // Thin, futuristic wireframe lines
  context.lineWidth = 0.5;
  context.beginPath();

  if (tesselationPairs && tesselationPairs.length > 0) {
    // The tesselation array is a flat list of index pairs: [start1, end1, start2, end2...]
    for (let i = 0; i < tesselationPairs.length; i += 2) {
      const startIdx = tesselationPairs[i];
      const endIdx = tesselationPairs[i + 1];
      
      const startPt = landmarks[startIdx];
      const endPt = landmarks[endIdx];

      if (startPt && endPt) {
        context.moveTo(startPt.x * width, startPt.y * height);
        context.lineTo(endPt.x * width, endPt.y * height);
      }
    }
  } else {
    // Fallback mapping that forces lateral connections across the face (preventing the nose cluster)
    for (let i = 0; i < landmarks.length; i++) {
      const pt = landmarks[i];
      const offsets = [15, 30, 45]; // Skip across index space to connect wider facial regions
      for (const offset of offsets) {
        const nextIdx = (i + offset) % landmarks.length;
        const nextPt = landmarks[nextIdx];
        if (pt && nextPt) {
          context.moveTo(pt.x * width, pt.y * height);
          context.lineTo(nextPt.x * width, nextPt.y * height);
        }
      }
    }
  }
  context.stroke();

  // Draw the bright micro tracking nodes
  context.fillStyle = "rgba(255, 255, 255, 0.6)";
  for (let i = 0; i < landmarks.length; i += 2) { // Step by 2 to save performance
    const pt = landmarks[i];
    if (pt) {
      context.beginPath();
      context.arc(pt.x * width, pt.y * height, 0.8, 0, Math.PI * 2);
      context.fill();
    }
  }
}

type DetectedItem = { name: string; box: number[] };
type OutfitCheckResult = {
  detected_items: DetectedItem[];

  harmony_score: number;
  occasion_fit: string;
  three_fixes: [string, string, string];
  vibe: string;
  style_archetype: string;
};

const MAX_FILE_BYTES = 4 * 1024 * 1024;
const ACCEPTED_TYPES = ["image/jpeg", "image/png", "image/webp"];
const LOADING_STEPS = ["Isolating garments", "Detecting fabrics", "Mapping colors", "Calculating harmony"];

export default function OutfitAnalysisPage() {
  const router = useRouter();
  const [file, setFile] = useState<File | null>(null);
  const [previewUrl, setPreviewUrl] = useState<string | null>(null);
  const [result, setResult] = useState<OutfitCheckResult | null>(null);
  const [editedItems, setEditedItems] = useState<DetectedItem[]>([]);
  const [isEditingItems, setIsEditingItems] = useState(false);
  const [isDragging, setIsDragging] = useState(false);
  const [isLoading, setIsLoading] = useState(false);
  const [isSaving, setIsSaving] = useState(false);
  const [saveStatus, setSaveStatus] = useState("");
  const [loadingStep, setLoadingStep] = useState(0);
  const [errorMessage, setErrorMessage] = useState<string | null>(null);

  useEffect(() => {
    if (!file) { setPreviewUrl(null); return; }
    const url = URL.createObjectURL(file);
    setPreviewUrl(url);
    return () => URL.revokeObjectURL(url);
  }, [file]);

  useEffect(() => {
    let interval: NodeJS.Timeout;
    if (isLoading) {
      setLoadingStep(0);
      interval = setInterval(() => { setLoadingStep((prev) => (prev < LOADING_STEPS.length - 1 ? prev + 1 : prev)); }, 1000);
    }
    return () => clearInterval(interval);
  }, [isLoading]);

  const selectFile = (selectedFile: File | undefined) => {
    if (!selectedFile) return;
    setErrorMessage(null); setResult(null); setEditedItems([]);
    if (!ACCEPTED_TYPES.includes(selectedFile.type)) { setFile(null); setErrorMessage("Choose a JPEG, PNG, or WebP image."); return; }
    if (selectedFile.size > MAX_FILE_BYTES) { setFile(null); setErrorMessage("Choose an image smaller than 4 MB."); return; }
    setFile(selectedFile);
  };

  const handleFileInput = (event: ChangeEvent<HTMLInputElement>) => { selectFile(event.target.files?.[0]); event.target.value = ""; };
  const handleDrop = (event: DragEvent<HTMLDivElement>) => { event.preventDefault(); event.stopPropagation(); setIsDragging(false); selectFile(event.dataTransfer.files[0]); };
  const handleDragOver = (event: DragEvent<HTMLDivElement>) => { event.preventDefault(); event.stopPropagation(); setIsDragging(true); };

    if (!file || isLoading) return;
    setIsLoading(true); setErrorMessage(null); setResult(null);
    const formData = new FormData(); formData.append("image", file);
    try {
      const response = await fetch("/api/outfit-check", { method: "POST", body: formData });
      const payload = await response.json();
      await new Promise(resolve => setTimeout(resolve, 4000)); 
      if (!response.ok) throw new Error(payload.error || "Analysis failed.");
      setResult(payload);
      setEditedItems(payload.detected_items);
    } catch (error: any) {
      setErrorMessage(error.message);
    } finally { setIsLoading(false); }
  };

  const cropImage = async (sourceFile: File, box: number[]): Promise<Blob> => {
    return new Promise((resolve, reject) => {
      const img = new window.Image();
      img.onload = () => {
        const canvas = document.createElement("canvas");
        const ctx = canvas.getContext("2d");
        if (!ctx) return reject("No canvas context");
        
        const ymin = (box[0] / 1000) * img.height;
        const xmin = (box[1] / 1000) * img.width;
        const ymax = (box[2] / 1000) * img.height;
        const xmax = (box[3] / 1000) * img.width;
        
        const width = xmax - xmin;
        const height = ymax - ymin;

        canvas.width = width;
        canvas.height = height;
        ctx.drawImage(img, xmin, ymin, width, height, 0, 0, width, height);
        
        canvas.toBlob((blob) => {
          if (blob) resolve(blob);
          else reject("Crop failed");
        }, "image/png");
      };
      img.src = URL.createObjectURL(sourceFile);
    });
  };

  const saveToCloset = async () => {
    if (!file || !result || isSaving) return;

        savedItems.push({ name: item.name, image_url: publicUrl });
      }

      setSaveStatus("Saving to cloud...");

        harmony_score: result.harmony_score,

  const supabase = await createClient();

  if (!user || user.email !== process.env.ADMIN_EMAIL) {
    return NextResponse.json({ 
      error: "Unauthorized", 
      userEmail: user?.email || "Not logged in" 
    }, { status: 401 });
  }

  const adminSupabase = createAdminClient(
    process.env.NEXT_PUBLIC_SUPABASE_URL!,
    process.env.SUPABASE_SERVICE_ROLE_KEY!
  );

  const [profiles, scans, waitlist] = await Promise.all([
    adminSupabase.from('profiles').select('*').order('created_at', { ascending: false }),
    adminSupabase.from('scans').select('*').order('created_at', { ascending: false }),
    adminSupabase.from('waitlist').select('*').order('created_at', { ascending: false })
  ]);

  return NextResponse.json({
    profiles: profiles.data || [],
    scans: scans.data || [],
    waitlist: waitlist.data || []
  });
}

        unlocks_count: 8,
        reason: "A clean white sneaker will seamlessly bridge your casual tops and tailored trousers.",
        search_query: "white leather sneakers"
      });
    }

    Analyze the gaps. What ONE single item (e.g., "White leather sneakers" or "Camel overcoat") should they buy that will mathematically unlock the most new outfit combinations with their existing clothes? 
    Return ONLY a valid JSON object with exactly these keys:
    - missing_item (string)
    - unlocks_count (number)
    - reason (string, 1 sentence)
    - search_query (string, 2-3 words)`;

    const response = await fetch("https://api.groq.com/openai/v1/chat/completions", {

      headers: { "Content-Type": "application/json", Authorization: `Bearer ${GROQ_API_KEY}` },
      body: JSON.stringify({
        model: GROQ_MODEL,
        messages: [{ role: "system", content: prompt }],
        response_format: { type: "json_object" }
      })
    });

    if (!response.ok) throw new Error("Groq API failed");
    
    const payload = await response.json();
    const rawContent = payload.choices[0].message.content;
    
    // Strip markdown if the model hallucinates it
    const cleanedContent = rawContent.replace(/```json/gi, "").replace(/```/g, "").trim();
    const result = JSON.parse(cleanedContent);
    
    return NextResponse.json(result);
  } catch (error) {
    console.error("Arbitrage Error:", error);
    // Return a mock result on failure so the UI doesn't break
    return NextResponse.json({ 
      missing_item: "Classic Beige Trench Coat",
      unlocks_count: 12,
      reason: "This transitional piece works with every dark and light layer you already own.",
      search_query: "beige trench coat"
    });
  }

const SYSTEM_PROMPT = `You are a high-end personal stylist and fashion director. Analyze the clothing items.
SAFETY: Evaluate clothing only. Never comment on the user's body.
Return ONLY a valid JSON object matching this schema: ${JSON.stringify(RESPONSE_SCHEMA)}.

type OutfitCheckResult = {
  detected_items: { name: string; box: number[] }[];
  dominant_colors: string[];
  harmony_score: number;
  occasion_fit: string;
  three_fixes: string[];
  vibe: string;
  style_archetype: string;
};

async function readBoundedBody(request: Request): Promise<ArrayBuffer | null> {
  const contentLength = Number(request.headers.get("content-length"));
  if (Number.isFinite(contentLength) && contentLength > MAX_REQUEST_BYTES) return null;
  if (!request.body) return new ArrayBuffer(0);
  const reader = request.body.getReader();
  const chunks: Uint8Array[] = [];
  let totalBytes = 0;
  while (true) {
    const { done, value } = await reader.read();
    if (done) break;
    totalBytes += value.byteLength;
    if (totalBytes > MAX_REQUEST_BYTES) { await reader.cancel(); return null; }
    chunks.push(value);
  }
  const body = new ArrayBuffer(totalBytes);
  const bodyBytes = new Uint8Array(body);
  let offset = 0;
  for (const chunk of chunks) { bodyBytes.set(chunk, offset); offset += chunk.byteLength; }
  return body;
}

function getImageMimeType(bytes: Uint8Array): string | null {
  if (bytes.length >= 3 && bytes[0] === 0xff && bytes[1] === 0xd8 && bytes[2] === 0xff) return "image/jpeg";
  if (bytes.length >= 8 && bytes[0] === 0x89 && bytes[1] === 0x50 && bytes[2] === 0x4e && bytes[3] === 0x47) return "image/png";
  if (bytes.length >= 12 && String.fromCharCode(...bytes.slice(0, 4)) === "RIFF" && String.fromCharCode(...bytes.slice(8, 12)) === "WEBP") return "image/webp";
  return null;
}

function isOutfitCheckResult(value: unknown): value is OutfitCheckResult {
  if (typeof value !== "object" || value === null) return false;
  const result = value as Record<string, unknown>;
  if (!Array.isArray(result.detected_items)) return false;
  for (const item of result.detected_items) {
    if (typeof item !== "object" || item === null) return false;
    const i = item as Record<string, unknown>;
    if (typeof i.name !== "string" || !Array.isArray(i.box) || i.box.length !== 4) return false;
  }
  return (
    Array.isArray(result.dominant_colors) && typeof result.harmony_score === "number" &&
    typeof result.occasion_fit === "string" && Array.isArray(result.three_fixes) && result.three_fixes.length === 3 &&
    typeof result.vibe === "string" && typeof result.style_archetype === "string"
  );
}

export async function POST(request: Request) {
  if (!request.headers.get("content-type")?.toLowerCase().startsWith("multipart/form-data")) {
    return NextResponse.json({ error: "Upload an image using multipart/form-data." }, { status: 415 });
  }
  const boundedBody = await readBoundedBody(request);
  if (!boundedBody) return NextResponse.json({ error: "The upload exceeds the request limit." }, { status: 413 });

  let formData: FormData;
  try {
    formData = await new Request(request.url, { method: "POST", headers: request.headers, body: boundedBody }).formData();
  } catch { return NextResponse.json({ error: "The multipart upload could not be read." }, { status: 400 }); }

  const image = formData.get("image");
  if (!(image instanceof File) || image.size === 0 || image.size > MAX_IMAGE_BYTES) return NextResponse.json({ error: "Invalid image." }, { status: 413 });

  const bytes = new Uint8Array(await image.arrayBuffer());
  const mimeType = getImageMimeType(bytes);
  if (!mimeType) return NextResponse.json({ error: "Use a valid JPEG, PNG, or WebP." }, { status: 415 });

  const apiKey = process.env.GROQ_API_KEY;
  if (!apiKey) return NextResponse.json({ error: "Outfit analysis is not configured yet." }, { status: 503 });

  const base64Image = Buffer.from(bytes).toString("base64");
  let providerResponse: Response;
  try {
    providerResponse = await fetch("https://api.groq.com/openai/v1/chat/completions", {
      method: "POST",
      headers: { "Content-Type": "application/json", Authorization: `Bearer ${apiKey}` },
      body: JSON.stringify({
        model: GROQ_MODEL,
        messages: [
          { role: "system", content: SYSTEM_PROMPT },
          { role: "user", content: [{ type: "text", text: "Review this outfit and return structured JSON." }, { type: "image_url", image_url: { url: `data:${mimeType};base64,${base64Image}` } }] },
        ],
      }),
      signal: AbortSignal.timeout(30_000),
    });
    if (!providerResponse.ok) throw new Error(await providerResponse.text());
  } catch (error) {
    console.error("Groq Failure:", error);
    return NextResponse.json({ error: "Outfit analysis is temporarily unavailable." }, { status: 502 });
  }

  let providerPayload: unknown;
  try { providerPayload = await providerResponse.json(); } catch { return NextResponse.json({ error: "Invalid Groq response." }, { status: 502 }); }

  const responseText = (providerPayload as any)?.choices?.[0]?.message?.content;
  if (!responseText) return NextResponse.json({ error: "Groq returned no feedback." }, { status: 502 });

  let result: unknown;
  try { result = JSON.parse(responseText.replace(/```json/gi, "").replace(/```/g, "").trim()); } 
  catch { return NextResponse.json({ error: "Groq returned invalid JSON." }, { status: 502 }); }

  if (!isOutfitCheckResult(result)) return NextResponse.json({ error: "Groq returned feedback in an invalid format." }, { status: 502 });

  return NextResponse.json(result);
}

// Safe parser to handle both old string-array data and new object-array data
function normalizeItems(rawItems: any, fallbackImage: string): { name: string; image: string }[] {
  if (!Array.isArray(rawItems)) return [];
  
  return rawItems.map((item, i) => {
    if (typeof item === "string") {
      // Old format: just a string
      return { name: item, image: fallbackImage };
    }
    if (typeof item === "object" && item !== null && "name" in item) {
      // New format: { name, image_url }
      return { name: item.name, image: item.image_url || fallbackImage };
    }
    return { name: "Unknown Item", image: fallbackImage };
  });
}

export default function ClosetPage() {
  const router = useRouter();
  const [cleanClosetData, setCleanClosetData] = useState<ClosetItem[]>([]);
  const [isLoading, setIsLoading] = useState(true);

  useEffect(() => {
    const fetchCloset = async () => {
      const supabase = createClient();
      const { data: { user } } = await supabase.auth.getUser();
      if (!user) {
        router.push("/login");
        return;
      }

      const { data } = await supabase
        .from("scans")
        .select("detected_items, image_url")
        .order("created_at", { ascending: false });

      if (data) {
        const itemMap = new Map<
          string,
          { name: string; totalWears: number; image: string; basePrice: number }
        >();

        data.forEach((scan) => {
          const items = normalizeItems(scan.detected_items, scan.image_url);
          
          items.forEach((item) => {
            if (!item.name || !item.name.trim()) return;
            
            const normalizedName = item.name
              .replace(/[^a-zA-Z0-9 ]/g, "")
              .trim()
              .toLowerCase();

            if (itemMap.has(normalizedName)) {
              const existing = itemMap.get(normalizedName)!;
              itemMap.set(normalizedName, {
                ...existing,
                totalWears: existing.totalWears + 1,
                image: existing.image || item.image,
              });
            } else {
              itemMap.set(normalizedName, {
                name: item.name,
                totalWears: 1,
                image: item.image,
                basePrice: Math.floor(Math.random() * 80) + 40,
              });
            }
          });
        });

        const finalData = Array.from(itemMap.entries()).map(([key, d]) => ({
          id: key,
          name: d.name,
          wears: d.totalWears,
          cpw: d.basePrice / d.totalWears,
          image: d.image,
        }));

        setCleanClosetData(finalData);
      }
      setIsLoading(false);
    };
    fetchCloset();
  }, [router]);

  if (isLoading) {
    return (

/* eslint-disable @next/next/no-img-element */
"use client";

import { useCallback, useEffect, useRef, useState } from "react";
import Link from "next/link";
import Image from "next/image";
import { GARMENTS } from "@/lib/tryon/catalogue";
import type { Garment, TryOnPhase, TryOnResult } from "@/lib/tryon/types";

const STAGES = [
  { key: "ingest", label: "Reading portrait silhouette" },
  { key: "geometry", label: "Simulating garment geometry" },
  { key: "drape", label: "Preparing preview composite" },
  { key: "composite", label: "Finalizing demo layout" },
];

export default function VirtualStudioPage() {
  const [phase, setPhase] = useState<TryOnPhase>("idle");
  const [loadingStep, setLoadingStep] = useState(0);
  const [selfie, setSelfie] = useState<File | null>(null);
  const [previewUrl, setPreviewUrl] = useState<string | null>(null);
  const [garment, setGarment] = useState<Garment | null>(null);
  const [result, setResult] = useState<TryOnResult | null>(null);
  const [error, setError] = useState<string | null>(null);

  // Canvas interaction state
  const [zoom, setZoom] = useState(1);
  const [offset, setOffset] = useState({ x: 0, y: 0 });
  const dragRef = useRef<{ x: number; y: number; ox: number; oy: number } | null>(null);

  useEffect(() => {
    return () => { if (previewUrl) URL.revokeObjectURL(previewUrl); };
  }, [previewUrl]);

  useEffect(() => {
    let interval: NodeJS.Timeout;
    if (phase === "generating") {
      setLoadingStep(0);
      interval = setInterval(() => {
        setLoadingStep((prev) => (prev < STAGES.length - 1 ? prev + 1 : prev));
      }, 1000);
    }
    return () => clearInterval(interval);
  }, [phase]);

  const onPickSelfie = useCallback((file: File | null) => {
    if (!file) return;
    setSelfie(file);
    setPreviewUrl((prev) => {
      if (prev) URL.revokeObjectURL(prev);
      return URL.createObjectURL(file);
    });
    setOffset({ x: 0, y: 0 });
    setZoom(1);
    setResult(null);
    setError(null);
    setPhase("ready");
  }, []);

  const generate = async () => {
    if (!selfie || !garment) return;
    setPhase("generating");
    setError(null);
    setResult(null);

    try {
      const body = new FormData();
      body.append("selfie", selfie);
      body.append("garmentId", garment.id);

      const res = await fetch("/api/try-on", { method: "POST", body });
      const data = await res.json();
      
      await new Promise(resolve => setTimeout(resolve, 4000));

      if (!res.ok) throw new Error(data.error || "Failed");

      setResult(data);
      setPhase("result");
    } catch (err) {
      setError(err instanceof Error ? err.message : "Something went wrong");
      setPhase("error");
    }
  };

  // ================= FULL SCREEN LOADING =================
  if (phase === "generating") {
    return (
      <main className="relative flex flex-col h-screen bg-[#000000] text-[#FFFFFF] items-center justify-center p-6">
        {previewUrl && (
          <Image src={previewUrl} alt="Blur" fill className="object-cover opacity-20 blur-xl" unoptimized />
        )}
        
        <div className="relative z-10 flex flex-col gap-6 w-full max-w-[280px]">
          <h2 className="text-[24px] font-black tracking-tighter text-center mb-4 text-[#FFFFFF]">Simulating...</h2>
          {STAGES.map((step, index) => {
            const isCompleted = index < loadingStep;
            const isActive = index === loadingStep;
            return (
              <div key={index} className={`flex items-center gap-4 transition-all duration-300 ${isCompleted ? "opacity-50" : isActive ? "opacity-100 scale-105" : "opacity-20"}`}>
                <div className={`h-8 w-8 rounded-full flex items-center justify-center border-2 shrink-0 ${isCompleted ? "bg-[#00FF66] border-[#00FF66]" : isActive ? "border-[#FFFFFF]" : "border-[#333333]"}`}>
                  {isCompleted && <span className="text-[#000000] text-[16px] font-black">✓</span>}
                  {isActive && <span className="h-3 w-3 bg-[#FFFFFF] rounded-full animate-pulse" />}
                </div>
                <span className={`text-[14px] font-bold uppercase tracking-widest ${isCompleted ? "text-[#888888] line-through" : "text-[#FFFFFF]"}`}>
                  {step.label}
                </span>
              </div>
            );
          })}
        </div>
      </main>
    );
  }

  const isReady = Boolean(previewUrl && garment);

  // ================= MAIN PAGE =================
  return (
    <main className="flex flex-col h-screen bg-[#000000] text-[#FFFFFF] overflow-hidden">
      
      {/* Header */}
      <header className="flex items-center justify-between px-6 py-6 shrink-0 border-b border-[#222222] z-10 bg-[#000000]">
        <Link href="/" className="text-[11px] font-bold uppercase tracking-widest text-[#888888]">
          ← Back
        </Link>
        <span className="text-[14px] font-black uppercase tracking-tighter">Virtual Studio</span>
        <div className="w-10"></div>
      </header>

      <div className="flex-1 flex flex-col px-6 py-6 overflow-y-auto">
        <h1 className="text-[32px] font-black leading-[1.05] tracking-tighter mb-4">
          Preview your <br />garments.
        </h1>
        
        {/* Canvas Area */}
        <div
          onPointerDown={(e) => { 
            if (!previewUrl) return; 
            e.currentTarget.setPointerCapture(e.pointerId); 
            dragRef.current = { x: e.clientX, y: e.clientY, ox: offset.x, oy: offset.y }; 
          }}
          onPointerMove={(e) => { if (!dragRef.current) return; setOffset({ x: dragRef.current.ox + (e.clientX - dragRef.current.x), y: dragRef.current.oy + (e.clientY - dragRef.current.y) }); }}
          onPointerUp={() => { dragRef.current = null; }}
          className="relative aspect-[3/4] w-full overflow-hidden rounded-[2rem] border-2 border-[#222222] bg-[#111111] touch-none mb-6 shrink-0 flex items-center justify-center"
        >
          {previewUrl ? (
            <>
              <img
                src={previewUrl} alt="Portrait" draggable={false}
                className="absolute left-1/2 top-1/2 max-h-none origin-center object-cover w-full h-full"
                style={{ transform: `translate(calc(-50% + ${offset.x}px), calc(-50% + ${offset.y}px)) scale(${zoom})` }}
              />
              {garment && (
                <div aria-hidden className="pointer-events-none absolute inset-0 mix-blend-soft-light opacity-40 transition-colors" style={{ backgroundColor: garment.swatch }} />
              )}
            </>
          ) : (
            <label className="absolute inset-0 z-50 flex cursor-pointer flex-col items-center justify-center bg-[#111111]">
              <input type="file" accept="image/jpeg,image/png,image/webp" className="absolute inset-0 h-full w-full opacity-0 cursor-pointer" onChange={(e) => onPickSelfie(e.target.files?.[0] ?? null)} />
              <span className="text-[14px] font-bold uppercase tracking-widest text-[#555555] mb-2">Tap to upload portrait</span>
            </label>
          )}
        </div>

        {/* Controls */}
        {previewUrl && (
          <div className="flex items-center gap-4 mb-6">
            <span className="text-[11px] font-bold uppercase tracking-widest text-[#888888]">Zoom</span>
            <input type="range" min={1} max={2.2} step={0.01} value={zoom} onChange={(e) => setZoom(Number(e.target.value))} className="h-1.5 flex-1 cursor-pointer appearance-none rounded-full bg-[#222222] accent-[#FFFFFF]" />
          </div>
        )}

        {/* Garment Carousel */}
        <div className="mb-8">
          <p className="text-[11px] font-bold uppercase tracking-widest text-[#888888] mb-3">Select Garment</p>
          <div className="flex gap-3 overflow-x-auto pb-4 snap-x">
            {GARMENTS.map((g) => (
              <button
                key={g.id}
                onClick={() => setGarment(g)}
                className={`snap-start shrink-0 w-36 p-3 rounded-2xl border text-left transition-all ${
                  garment?.id === g.id 
                    ? "border-[#FFFFFF] bg-[#222222] ring-2 ring-[#FFFFFF] ring-offset-2 ring-offset-[#000000]" 
                    : "border-[#222222] bg-[#111111] opacity-70 hover:opacity-100"
                }`}
              >
                <div className="h-16 w-full rounded-lg mb-3" style={{ background: `linear-gradient(145deg, ${g.swatch} 0%, ${g.swatch}dd 55%, #0d0d0f 140%)` }} />
                <p className="text-[12px] font-bold text-[#FFFFFF] leading-tight mb-1 truncate">{g.name}</p>
                <p className="text-[10px] text-[#888888] uppercase tracking-wider">{g.brand}</p>
              </button>
            ))}
          </div>
        </div>

        {error && <p className="text-[12px] text-red-500 font-medium text-center mb-4">{error}</p>}
      </div>

      {/* Bottom Action Area */}
      <div className="px-6 pb-8 pt-4 shrink-0 bg-gradient-to-t from-black via-black to-transparent z-10">
        {phase === "result" ? (
          <div className="flex flex-col gap-3">
            <div className="bg-[#111111] border border-[#222222] rounded-2xl p-4 text-center">
              <p className="text-[11px] font-bold uppercase tracking-widest text-[#00FF66] mb-1">Preview Mode</p>
              <p className="text-[12px] text-[#888888] leading-relaxed">{result?.message}</p>
            </div>
            <button
              onClick={() => { setPhase("ready"); setResult(null); }}
              className="w-full flex items-center justify-center bg-[#111111] border border-[#222222] text-[#FFFFFF] h-[64px] rounded-full active:scale-[0.96] transition-transform font-black uppercase tracking-widest text-[14px]"
            >
              Scan Another
            </button>
          </div>
        ) : (
          <button

"use client";

import { useState } from "react";
import { useRouter } from "next/navigation";
import Link from "next/link";
import { createClient } from "@/lib/supabase/client";

export default function LoginPage() {
  const router = useRouter();
  const [isLogin, setIsLogin] = useState(true);
  const [email, setEmail] = useState("");
  const [password, setPassword] = useState("");
  const [loading, setLoading] = useState(false);
  const [errorMessage, setErrorMessage] = useState<string | null>(null);
  const [successMessage, setSuccessMessage] = useState<string | null>(null);

  const handleAuth = async (e: React.FormEvent) => {
    e.preventDefault();
    setLoading(true);
    setErrorMessage(null);
    setSuccessMessage(null);

    const supabase = createClient();

    try {
      if (isLogin) {
        const { error } = await supabase.auth.signInWithPassword({ email, password });
        if (error) throw error;
        router.push("/dashboard");
        router.refresh();
      } else {
        const { error } = await supabase.auth.signUp({ email, password });
        if (error) throw error;
        setSuccessMessage("Check your email for the confirmation link.");
        setIsLogin(true);
      }
    } catch (error) {
      setErrorMessage(error instanceof Error ? error.message : "An error occurred");
    } finally {
      setLoading(false);
    }
  };

  return (
    <main className="flex flex-col h-screen bg-[#000000] text-[#FFFFFF] overflow-hidden">
      
      {/* Header */}
      <header className="flex justify-between items-center px-6 py-8 shrink-0">
        <Link href="/" className="text-[11px] font-bold uppercase tracking-widest text-[#888888]">
          ← Back
        </Link>
        <span className="text-[11px] font-bold uppercase tracking-widest text-[#555555]">
          {isLogin ? "Welcome Back" : "Create Account"}
        </span>
      </header>

      {/* Main Content */}
      <div className="flex-1 flex flex-col justify-center px-6 pb-12 w-full max-w-md mx-auto">
        
        <div className="mb-10 text-center">
          <h1 className="text-[52px] font-black leading-[1.0] tracking-tighter mb-3">
            {isLogin ? "Sign in." : "Join the beta."}
          </h1>
          <p className="text-[14px] text-[#888888] leading-relaxed max-w-[260px] mx-auto">
            {isLogin
              ? "Access your digital wardrobe and daily style intelligence."
              : "Start building your cloud-synced closet today."}
          </p>
        </div>

        <form onSubmit={handleAuth} className="flex flex-col gap-5 w-full">
          <div>
            <label className="text-[10px] font-bold uppercase tracking-widest text-[#555555] mb-2 block ml-1">Email</label>
            <input
              type="email"
              value={email}
              onChange={(e) => setEmail(e.target.value)}
              placeholder="you@example.com"
              required
              className="w-full bg-[#111111] border border-[#222222] text-[#FFFFFF] text-[15px] px-5 py-4 rounded-2xl focus:outline-none focus:border-[#FFFFFF] transition-colors placeholder:text-[#444444]"
            />
          </div>
          
          <div>
            <label className="text-[10px] font-bold uppercase tracking-widest text-[#555555] mb-2 block ml-1">Password</label>
            <input
              type="password"
              value={password}
              onChange={(e) => setPassword(e.target.value)}
              placeholder="••••••••"
              required
              className="w-full bg-[#111111] border border-[#222222] text-[#FFFFFF] text-[15px] px-5 py-4 rounded-2xl focus:outline-none focus:border-[#FFFFFF] transition-colors placeholder:text-[#444444]"
            />
          </div>

          {errorMessage && <p className="text-[12px] text-red-500 font-medium text-center" role="alert">{errorMessage}</p>}
          {successMessage && <p className="text-[12px] text-[#00FF66] font-medium text-center" role="status">{successMessage}</p>}

          <button
            type="submit"
            disabled={loading}
            className="w-full flex items-center justify-center bg-[#FFFFFF] text-[#000000] h-[68px] rounded-full active:scale-[0.96] transition-transform font-black uppercase tracking-widest text-[15px] disabled:opacity-50 mt-2"
          >
            {loading ? "Processing..." : isLogin ? "Sign In" : "Create Account"}
          </button>
        </form>

        <div className="mt-8 text-center">
          <button
            type="button"
            onClick={() => { setIsLogin(!isLogin); setErrorMessage(null); setSuccessMessage(null); }}
            className="text-[13px] font-medium text-[#888888] hover:text-[#FFFFFF] transition-colors"
          >
            {isLogin ? "Don't have an account? Sign up" : "Already have an account? Sign in"}
          </button>
        </div>
      </div>
    </main>
  );
}

===== src/lib/colorMath.ts =====
export type RGB = readonly [red: number, green: number, blue: number];

export type SkinColorSamples = {
  cheeks: readonly RGB[];
  forehead: readonly RGB[];
};

export type Undertone = "warm" | "cool" | "neutral" | "olive";

export type UndertoneAnalysis = {
  undertone: Undertone;
  averageRgb: RGB;
  lab: { lightness: number; a: number; b: number };
  hueAngle: number;
};

function averageRgb(samples: readonly RGB[]): RGB {
  if (samples.length === 0) {
    throw new RangeError("At least one skin color sample is required.");
  }

  const total = samples.reduce(
    ([red, green, blue], sample) => {
      for (const channel of sample) {
        if (!Number.isFinite(channel) || channel < 0 || channel > 255) {
          throw new RangeError("RGB channels must be finite values from 0 to 255.");
        }
      }

      return [red + sample[0], green + sample[1], blue + sample[2]];
    },
    [0, 0, 0],
  );

  return [
    total[0] / samples.length,
    total[1] / samples.length,
    total[2] / samples.length,
  ];
}

function srgbToLinear(channel: number): number {
  const value = channel / 255;
  return value <= 0.04045
    ? value / 12.92
    : ((value + 0.055) / 1.055) ** 2.4;
}

function rgbToLab([red, green, blue]: RGB): UndertoneAnalysis["lab"] {
  const linearRed = srgbToLinear(red);
  const linearGreen = srgbToLinear(green);
  const linearBlue = srgbToLinear(blue);

  const x = (linearRed * 0.4124564 + linearGreen * 0.3575761 + linearBlue * 0.1804375) / 0.95047;
  const y = linearRed * 0.2126729 + linearGreen * 0.7151522 + linearBlue * 0.072175;
  const z = (linearRed * 0.0193339 + linearGreen * 0.119192 + linearBlue * 0.9503041) / 1.08883;

  const pivot = (value: number) =>
    value > 0.008856451679
      ? Math.cbrt(value)
      : value / 0.1284185493 + 0.1379310345;
  const xPivot = pivot(x);
  const yPivot = pivot(y);
  const zPivot = pivot(z);

  return {
    lightness: 116 * yPivot - 16,
    a: 500 * (xPivot - yPivot),
    b: 200 * (yPivot - zPivot),
  };
}

function classifyUndertone(hueAngle: number, chroma: number): Undertone {
  if (chroma < 8) return "neutral";
  if (hueAngle >= 75 && hueAngle <= 115) return "olive";
  if (hueAngle >= 50 && hueAngle < 75) return "warm";
  if (hueAngle < 50 || hueAngle > 340) return "cool";
  return "neutral";
}

export function analyzeUndertone(samples: SkinColorSamples): UndertoneAnalysis {
  const average = averageRgb([...samples.cheeks, ...samples.forehead]);
  const lab = rgbToLab(average);
  const hueAngle = (Math.atan2(lab.b, lab.a) * 180 / Math.PI + 360) % 360;
  const chroma = Math.hypot(lab.a, lab.b);
  const undertone = classifyUndertone(hueAngle, chroma);
  const analysis = { undertone, averageRgb: average, lab, hueAngle };

  console.log("Estimated skin undertone:", undertone, analysis);
  return analysis;
}

===== src/middleware.ts =====
import { createServerClient } from "@supabase/ssr";
import { NextResponse, type NextRequest } from "next/server";

export async function middleware(request: NextRequest) {
  let supabaseResponse = NextResponse.next({
    request,
  });

  const supabase = createServerClient(
    process.env.NEXT_PUBLIC_SUPABASE_URL!,
    process.env.NEXT_PUBLIC_SUPABASE_ANON_KEY!,
    {
      cookies: {
        getAll() {
          return request.cookies.getAll();
        },
        setAll(cookiesToSet) {
          cookiesToSet.forEach(({ name, value }) => request.cookies.set(name, value));
          supabaseResponse = NextResponse.next({
            request,
          });
          cookiesToSet.forEach(({ name, value, options }) =>
            supabaseResponse.cookies.set(name, value, options)
          );
        },
      },
    }
  );

  // IMPORTANT: Avoid writing any logic between createServerClient and
  // supabase.auth.getUser(). A simple mistake could make it very hard to debug
  // issues with users being randomly logged out.

  await supabase.auth.getUser();

  return supabaseResponse;
}

export const config = {
  matcher: [
    /*
     * Match all request paths except for the ones starting with:
     * - _next/static (static files)
     * - _next/image (image optimization files)
     * - favicon.ico (favicon file)
     * Feel free to modify this to fit your needs.
     */
    "/((?!_next/static|_next/image|favicon.ico|.*\\.(?:svg|png|jpg|jpeg|gif|webp)$).*)",
  ],
};

begin;

create table if not exists public.waitlist (
  id bigint generated by default as identity primary key,
  email text not null unique,
  created_at timestamptz not null default now()
);

alter table public.waitlist
  alter column email set not null,
  alter column created_at set default now(),
  alter column created_at set not null;

alter table public.waitlist
  drop constraint if exists waitlist_email_check;

alter table public.waitlist
  drop constraint if exists waitlist_email_length_check;

alter table public.waitlist
  add constraint waitlist_email_length_check
  check (char_length(email) <= 254);

alter table public.waitlist enable row level security;

do $$
declare
  existing_policy record;
begin
  for existing_policy in
    select policyname
    from pg_policies
    where schemaname = 'public'
      and tablename = 'waitlist'
  loop
    execute format(
      'drop policy %I on public.waitlist',
      existing_policy.policyname
    );
  end loop;
end
$$;

revoke all on table public.waitlist from anon, authenticated;
grant insert on table public.waitlist to anon;

create policy "Allow public waitlist signups"
on public.waitlist
for insert
to anon
